Capture. Compile. Prove.

Receipts turns agent work into evidence that a Prime agent can inspect before it builds on the result.

Run at the boundary

Execute the command once, capture its exit code, hash its output, and keep the event in a tamper-evident chain.

Compile what is real

Verify the source receipts and turn them into a deterministic packet the next pass can read without replaying chat.

Gate the claim

A passing sentence is not enough. The gate checks the latest receipt and mechanically refutes a claim that the evidence contradicts.

Hand off to Prime

Give the next agent next_pass_packet.json, the verified snapshot, and the decision log in one compact handoff.

Keep artifacts addressable

Command output is stored by content hash, so a later agent can point back to the exact bytes behind a decision.

Make failure useful

A failed receipt is a useful result: it stops Prime from building on a false green and tells the next pass where to look.

Stay open and inspectable

Receipts is an open-source compiler for agent orchestrations: the contract is visible, the packet is portable, and the proof is yours.

Ready for the next pass

The handoff is concise enough for an agent to act on and specific enough for a human to audit later.
